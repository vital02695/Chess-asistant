# Chess Assistant

Находит шахматную доску на экране Android, распознаёт позицию, считает Stockfish'ем лучший ход,
рисует стрелки: зелёная — ваш ход, красные — вероятные ответы соперника с процентами; сверху полоса оценки.

## 1. Положить Stockfish (обязательно, один раз)
Приложению нужен бинарник Stockfish для Android (arm64, 64-бит).
1. Скачайте с https://github.com/official-stockfish/Stockfish/releases (или https://stockfishchess.org/download/)
   сборку **Android, armv8** (файл вида `stockfish-android-armv8`; внутри архива).
2. Переименуйте файл в **libstockfish.so**.
3. Положите в `app/src/main/jniLibs/arm64-v8a/libstockfish.so`.
Нейросеть оценки (NNUE) в официальных сборках уже внутри файла.

## 2. Сборка
Android Studio (Koala+) → File → Open → папка проекта → Gradle Sync → подключить телефон (отладка по USB) → Run.

## 3. Использование
1. «Запустить», разрешения.
2. Откройте страницу с шахматами, расставьте начальную позицию.
3. В панели нажмите «Белые↓ (кал.)» или «Чёрные↓ (кал.)» (кто снизу). Один раз.
4. Играйте. Панель можно перетаскивать за текст и сворачивать кнопкой ▼.

Кнопки: Флип (если доска перевёрнута) · Ход (чей ход; обычно определяется сам) ·
Соперник (новичок/средний/сильный: влияет на проценты) · Авто (постоянный скан) ·
Скан (разовый, если Авто выключено — без мерцания) · Бейджи (показ распознанных фигур) · Стоп.

## Заметки
- Оверлей попадает в захват экрана, поэтому перед каждым кадром он на ~0,25 с прячется (лёгкое мерцание).
  Выключите «Авто» и жмите «Скан» после хода — мерцания не будет.
- Проценты — приближение: Stockfish ранжирует ходы соперника, температура зависит от выбранного уровня.
- Распознаются фигуры с тёмным контуром (в т.ч. ваша тема). Сменили тему/набор фигур — перекалибруйте.
- Права на рокировку определяются по расположению короля/ладей; взятие на проходе не учитывается.
- Stockfish распространяется под GPLv3.
